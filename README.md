# Memory Game
 
This project is an HTML page built with React.js, using the library's component-based concepts. The application is a memory game that works by manipulating components through conditional rendering. The goal of the game is to match the names of galaxies with their respective images.
 
The application can be accessed at: https://memorygame-s319.onrender.com/ or started locally (see the "Running locally" section)

## Running locally
 
Clone the project
 
```bash
  git clone https://github.com/Caique27/MemoryGame.git
```
 
Go to the project directory
 
```bash
  cd MemoryGame
```
 
Install the dependencies
 
```bash
  npm install
```
 
Start the server
 
```bash
  npm start
```
 
Access the application at:
 
```bash
  https://localhost:3000/
```
